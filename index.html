Enquadramento da formação

Capacitar os formandos a desenvolver páginas web estáticas utilizando tecnologias base como HTML, CSS e introdução ao JavaScript, aplicando boas práticas do desenvolvimento web.

Pré-requisitos

  • Conhecimentos básicos de informática.
  • Noções básicas de uso de computador e Internet.

Metodologia

Método expositivo-demonstrativo (30%) e método activo com prática orientada (70%). Cada conceito é demonstrado pelo formador e logo aplicado num exercício pelos formandos.

Recursos necessários

  • 1 computador por formando, com VS Code e navegador actualizado.
  • Projector e ligação à Internet.
  • Conta de e-mail pessoal para o GitHub (Dia 5).

    Apresentações

    Uma apresentação por dia, para projectar em sala. Os exemplos de código podem ser executados no próprio diapositivo e cada apresentação inclui perguntas de revisão, o exercício do dia e notas para o formador.

    • 🌐Dia 1Como a Web funciona e a primeira páginaInternet, cliente e servidor, ferramentas, estrutura HTML, links e imagens
    • 🧱Dia 2HTML completo e os primeiros estilosListas, tabelas, formulários, semântica, seletores, cores e fontes
    • 🎨Dia 3Layout e design responsivoBox model, Flexbox, Grid e media queries
    • ⚡Dia 4Interactividade com JavaScriptVariáveis, condicionais, funções, DOM, eventos e briefing do projecto
    • 🚀Dia 5Publicação e projecto finalHospedagem, estrutura de ficheiros, GitHub Pages e apresentações

    Durante a apresentação: ← → para navegar, I para o índice, N para as notas do formador, F para ecrã inteiro. Em telemóvel, deslize para os lados.

    Projecto final

    Cada formando desenvolve e publica um website completo, com pelo menos três páginas ou secções. O briefing é feito no final do Dia 4 e o desenvolvimento ocorre no Dia 5.

    Temas sugeridos

    • Portfólio pessoal ou currículo online.
    • Página de um negócio local (restaurante, salão, oficina).
    • Página de divulgação de um evento.
    • Website de uma associação, igreja, clube ou escola.
    • Tema livre, validado pelo formador.

    Ver o projecto exemplo (Restaurante Kianda)

    Requisitos mínimos

    • Estrutura semântica (header, nav, main, footer).
    • Imagens com texto alternativo, uma lista e um formulário.
    • CSS externo com Flexbox ou Grid.
    • Adaptação a telemóvel com pelo menos uma media query.
    • Uma interacção em JavaScript (ex.: validação, menu, modo escuro).
    • Publicação no GitHub Pages com link funcional.

    Riscos, premissas e dependências

    TipoDescriçãoMitigação
    RiscoRitmos de aprendizagem diferentes entre formandos.Exercícios com nível base e desafio extra; formandos mais rápidos apoiam colegas.
    RiscoFalha de Internet no dia da publicação.Ter rede alternativa (hotspot) e permitir publicar após a sessão, com prazo definido.
    RiscoComputadores sem permissão para instalar software.Confirmar com a área de TI antes do Dia 1; alternativa: editor online (ex.: CodePen).
    PremissaCada formando dispõe de um computador durante as 20 horas.Validar a sala e o equipamento na véspera.
    DependênciaConta pessoal no GitHub, criada pelo próprio formando.Pedir a criação da conta como trabalho de casa no Dia 4.
    ConformidadeUso de imagens e textos de terceiros nos projectos.Usar conteúdo próprio ou de bancos livres de direitos; não publicar dados pessoais de terceiros.
