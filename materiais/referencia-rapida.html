Grid (duas dimensões) e responsivo

.grelha {
  display: grid;
  grid-template-columns: 1fr;   /* telemóvel */
  gap: 20px;
}
.destaque { grid-column: span 2; }

@media (min-width: 600px) {     /* tablet e acima */
  .grelha { grid-template-columns: repeat(3, 1fr); }
}

Mobile-first: CSS do telemóvel primeiro, depois min-width. Teste com Ctrl + Shift + M nas DevTools.

Publicação no GitHub Pages

Passos

  1. New repository, nome (ex.: meu-site), Public.
  2. Add file > Upload files: arraste o conteúdo da pasta (não a pasta).
  3. Mensagem e Commit changes.
  4. Settings > Pages: Deploy from a branch, main, / (root), Save.
  5. Abrir https://utilizador.github.io/meu-site/ após alguns minutos.

A interface do GitHub pode mudar ligeiramente.

Antes de publicar

  • index.html na raiz, em minúsculas.
  • Caminhos relativos (css/estilo.css, ../img/x.jpg), nunca C:\…
  • Nomes de ficheiros iguais no HTML e na pasta (maiúsculas contam).
  • Imagens com alt e abaixo de ~300 KB.
  • Funciona no modo telemóvel e a consola não tem erros.
  • Cada página tem um <title> próprio.
  • Sem dados pessoais de terceiros nem conteúdo sem autorização.
